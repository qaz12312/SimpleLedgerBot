## 未來項目
* feat: 可以輸入`{西元年分}{月份}`得到該月資料
* feat: 可以輸入`{類別}`得到歷年該類別的花費總金額
* feat: 可以指定時間輸入`{年月日} 金額 說明 @分類`，來記錄忘記填寫的非當日支出
* feat: 可以刪除誤填的紀錄，根據line回復訊息上的`#id`，以輸入`刪除#id`來移除某一筆(如果紀錄有被動到怎麼辦?)
* feat: 可以有收入，金額前面用`+`代表收入；`-`代表支出
* 月度報表
    - 顯示月度總支出
    - 顯示記帳次數
    - 顯示最高單筆與最低單筆
    - 顯示分類統計
    - 顯示日均消費
    - 顯示消費分析
    - 顯示本月趨勢分析
        1. 先把當月記錄按週整理，算出每週支出
        2. 再把前半週和後半週的平均支出做比較，判斷是上升、下降或持平
* 年度報表
    - 顯示年度總支出
    - 顯示年度記帳總次數
    - 顯示月平均支出(月均消費)
    - 顯示年度最高單筆
    - 顯示年度分類統計
    - 顯示月度趨勢分解
* 趨勢比較
    - 比較本月總支出和上個月總支出
    - 比較本月總支出和去年同月總支出
    - 顯示今年到目前為止的年度累計支出
* fix: 連續輸入多筆紀錄請求時，會有部分紀錄沒有被寫入
* 優化處理效能
